# KINETIC AD STUDIO — Interactive 3D Engineering Workshop

A professional, fully interactive 3D simulator for designing, inspecting, animating and learning the **Kinetic Ad Studio** (2×2 kinetic RGB LED advertising display) before building the physical device.

## Repository

https://github.com/axionwave123/kinetic-ad-studio

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Engineering note

All mechanical dimensions, servo ratings, LED specifications and ESP32 pin assignments are **conceptual** until validated. The simulator is a learning and design tool, not a substitute for validated engineering drawings.
